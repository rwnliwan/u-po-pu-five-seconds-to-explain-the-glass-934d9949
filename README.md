## The entry

> I poked it once to check if it was alive — it never moved, never blinked, so I cleared it off my table.

One sentence, 103 characters. A house cat's defence, five seconds after sweeping a glass off the table: no apology, no confession. The cat was running a prey test — poking a suspicious object to see if it is alive — and the glass failed it, so the table was cleared. Pure cat logic, zero remorse.
